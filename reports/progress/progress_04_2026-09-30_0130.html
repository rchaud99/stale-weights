Stale Weights: progress report 04

2026-09-30 01:30 EDT · cloud study v2 · Qwen2.5-14B core (airline 5 seeds, returns 3 seeds)
Where things stand. The study was rebuilt on the cloud (Modal H100s, bf16, PEFT + vLLM) with every fix from the two red-team reviews: class-balanced training data, paraphrased number-first replies, test sets centred on the threshold, unambiguous boundary wording, a separate gate set and a sampled primary metric. The core for Qwen2.5-14B is done: airline 5 seeds, retail returns 3 seeds. The main result holds in 5 of the 6 preregistered cells. When a rule is left out of the new prompt and the prompt says "apply only the rules written in this policy", a model fine-tuned on old decisions still reaches for the old rule, and the same-data control trained with the policy text in its prompts does not. How strongly that shows depends on decoding and domain. In returns it is visible even in greedy decisions. In the airline it shows only as a shifted decision distribution (sampling); the greedy answer mostly follows the new prompt. Writing the removal out explicitly fixes it in every domain. A change notice does not.

LTC is the local threshold contrast: mean P(deny) just above the old limit minus just below it (T to 2T vs T/2 to T; for categories, trained final-sale items vs other items). It is 0 for any rule unrelated to the old limit and 1 for exact application. "Replicates" needs Holm p < .05, a CI lower bound above +0.15, and every seed (4/5 for the airline) positive. "Applies the old number" also needs tuned P(deny) ≥ .5 above and ≤ .5 below; otherwise the verdict is "cites".

Caveat on returns B-window's ΔLTC (+0.81). The control does not stay at zero. It fills the omitted window with the base model's generic 30-day window, written in the trained template ("Policy limit: 30 days … 59 >= 30"). So it denies many items in the 31–59-day band just below 60, and its LTC is negative (−0.17). This inflates the tuned-minus-control contrast. The conservative estimate is tuned minus the untuned base: +0.31 (p = 0.008). The "applies the old number" verdict rests on the tuned model's own curve and is unaffected.

3. Mitigations and the "before" rows

  • Stating the removal explicitly ("there is no time limit" / "no category is final sale") cuts greedy conflict denials by 0.40–0.87 in all 4 returns families (p ≤ 0.005). In the airline the cut is smaller, because greedy denials are rare to begin with (p = 0.06–0.10, 5 seeds).
  • The change notice is not a fix. In the airline, notice vs a neutral sentence is −0.16 / −0.17. In returns, the A window rises by 14 points (p = 0.015); the other cells are n.s.
  • Before fine-tuning (the untuned base): the airline LTC is ≈ 0, with 0–1/480 greedy conflict denials. Returns categories are 0. The returns B window's base LTC is +0.33, because the base denies some old items on its own.
